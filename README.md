# Noo Atlas

**An interactive atlas for Earth and other celestial bodies.**

Noo Atlas is being developed as a standalone tool for exploring geographic and planetary data, and as a foundation for spatial visualization within [Noopedia](https://noopedia.org/).

**Project website:** [koralex.com/atlas/](https://koralex.com/atlas/)

## Project status

🚧 **Under active development.**

App preview is ready to download in release section.

The source code is not public yet. **It will be published in this repository as soon as the project's core functional goals have been achieved.**

The aim is to release a coherent, usable foundation rather than an unfinished prototype. No release date has been announced.

Thank you for your interest in Noo Atlas!
